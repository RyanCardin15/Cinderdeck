# Packaging

Build the complete Cinderdeck app with [build-unified.sh](../../../scripts/build-unified.sh). The runtime builder produces the private `AgentShell.app` child, with no independent updater or URL registration. Native Cinderdeck owns identity, signing and Sparkle updates. Preserve all original licenses and copyright notices. See [the unified-app guide](../../../docs/UNIFIED_APP.md).
