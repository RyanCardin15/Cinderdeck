# Cinderdeck promo source

A 48-second native product demo with real SwiftUI/AppKit renders and fictional local fixtures.

See [the production guide and scene description](../docs/PROMO.md) for capture, render, export, and validation instructions.

```sh
npm ci
npm run dev       # editable preview
npm run render    # MP4, GIF, poster, and validation manifest
npm run capture   # rebuild native artwork, then all exports
```

The seven scenes are individually editable in `src/scenes/`. `public/screens/` contains 2× native renders. `public/score.wav` is generated by `scripts/score.py`; `public/icon.png` is the existing Cinderdeck icon. Keep sample data labels and muted readability when editing.
