# From customized Snapzy to Cinderdeck

The customized Snapzy fork is now **Cinderdeck**, an independent native macOS development application maintained by Ryan Cardin. Its source baseline is [Snapzy 1.32.3](https://github.com/duongductrong/Snapzy), commit `9f48e030`, created by Trong Duong Duc and contributors. The original BSD 3-Clause license remains in [LICENSE](../LICENSE).

Use the [main README](../README.md) for the current product, [BUILD.md](BUILD.md) for builds, and [MIGRATION.md](MIGRATION.md) for existing installations. The Cinderdeck release line starts at 1.0.0, build 200.

The original customization added opt-in local clipboard text history and configurable development stacks. Agent control, a CLI, and an MCP server extend the same local service supervisor. Capture, recording, and editing capabilities continue to come from the Snapzy foundation.

See [HISTORY.md](HISTORY.md), [STACKS.md](STACKS.md), and [STACKS_IMPLEMENTATION.md](STACKS_IMPLEMENTATION.md) for feature details and historical verification records. Logs and build artifacts in those records describe the feature delivery at the time; they are not published release assets.
