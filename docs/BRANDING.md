# Cinderdeck identity

**Cinderdeck** is a development control deck for macOS. The product combines user-defined projects and services, terminal and agent control, and the capture and clipboard tools useful while building software.

- Product and repository: `Cinderdeck`
- Command and URL scheme: `cinderdeck`
- Bundle identifier: `com.ryancardin.cinderdeck` (`.debug` for development)
- Palette: charcoal with ember orange (`#FF661C`)
- Master icon: [`assets/cinderdeck-icon.png`](../assets/cinderdeck-icon.png)
- Menu-bar glyph: native template drawing in `MenuBarIconRenderer.swift`

The app icon was generated using the built-in image generation tool, then resized into the macOS asset catalog. Prompt:

> Create a production-ready macOS application icon for Cinderdeck, a native development control deck for managing local projects, services, terminals and coding agents. Single square 1024x1024 image with genuine transparent background outside a macOS rounded-square icon tile. Tile fills 88 percent of the image, centered, charcoal black anodized metal, subtly dimensional precision bevel. Bold centered geometric ember-orange C glyph formed from three stacked angular rails, the negative space suggesting a terminal prompt chevron and control deck. Minimal, iconic, serious professional developer tool, crisp silhouette readable at 16px. Warm orange to pale amber highlight on upper surfaces, very subtle ember glow, no literal fire, no sparks, no screens, no letters or text beyond the abstract C mark, no watermark. Front view, no perspective tilt, no extra objects. Sophisticated restrained industrial design. This is a brand new original icon, not resembling a screenshot/camera icon.
